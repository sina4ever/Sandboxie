# Sandboxie (community fork, Windows, C/C++ + Qt)

Large repo (~1600 files). Never grep the whole tree; scope to one dir.

- `Sandboxie/` core driver and DLLs, `SandboxiePlus/` Qt UI, `SandboxieTools/`, `Installer/`.
- Read `CONTRIBUTING.md` and `TRANSLATING.md` only for those tasks. Skip `CHANGELOG*.md` and `*_zh_CN.md`.
- Builds need Windows (MSVC, Qt); they cannot run in this Linux environment. Do not claim a build or test passed.
- Add a user-visible change to `CHANGELOG.md`; follow `.github/pull_request_template.md`.
